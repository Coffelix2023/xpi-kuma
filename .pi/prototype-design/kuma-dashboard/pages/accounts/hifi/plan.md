# plan.md — hifi (kuma-dashboard / accounts)

> 本阶段唯一需求事实来源。每轮深挖后**覆写本文件**，不新建副本。

## 1. 目的 (Why)

把线框 `pages/accounts/wireframe/`（v1）做成单文件高保真：让「这个余额数字是怎么来的」
一眼可辨，拿不到值的行有明确下一步。

## 2. 受众 (Who)

xpi-kuma 开源用户，多为中转服务商用户；余额随时耗尽，服务商未必提供查询接口。

## 3. 范围

### 包含

- 结构 1:1 继承线框：头部 / 账户概览 / 供应商账户列表 / 空态说明
- 数据来源三档的视觉语言：实线 = API、虚线 = OAuth、点线 = 手动（沿用线框的边线编码，
  升级为可读的徽标样式并配主题色）
- 手动值在界面上与自动值可区分（弱化 + 标注）
- 与主面板互链、亮暗切换、中英切换（与主面板同一套实现）

### 不包含

- 授权弹窗 / 手填表单：线框未定义，本阶段只保留入口按钮（新增结构需先确认）
- 供应商余额 API 探测、OAuth 接入、写盘路径 —— 全为实现阶段
- 真实数据接线（内联样例数据）
